🧭 02) Create a Workspace
===========================
🏆 Goal: Make a project directory and move into it.

1️⃣ Type cd .. to return to the CL_1 parent folder

2️⃣ Type mkdir research_project

💡Why: mkdir means "make directory". You can use this command to create a new folder that will be called whatever name you indicate after the mkdir command (in this case "research_project").

✨Tip: Running mkdir will create a new folder that will be located wherever you are when you input the command. We want the research project folder to be located in the CL_1 parent folder, which is why we used cd .. to navigate to CL_1 before running the mkdir command.
