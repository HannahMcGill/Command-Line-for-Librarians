🧭 4) Read Data Files
=======================
🏆 Goal: Practice quick inspection of data files.

1️⃣ Type cd .. to return to your parent folder.

2️⃣ Type cd research_project (or use cd and the tab key) to move to the research project folder.

❗ Before you run the next command, know that once you do, you will be opening and reading a structured data set. Even 10 or 15 lines of JSON can feel like a lot if you aren't use to reviewing data like this. The goal of this exercise is just to get comfortable moving through the file and not to understand every word of it. 

👉 To move through the data use:
  space  = scroll forward
  b      = scroll back
  /term  = search for “term” (e.g. any word you want to search for, the way you would using command+f in a text document)

❗ You will need to use the command 👉 q 👈 to navigate back to the command line. You will not be able to see these instructions while you are reviewing the JSON data, so make sure you remember that q will take you back to terminal. You can always return to terminal and run the command to read the JSON files again if you want to review how to move through the data. 

3️⃣ Type less papers.json and then q when you are comfortable with the keyboard commands and ready to move on.

💡 Why: less lets you scroll through a file page by page.

✨ Tip: While cat is great for reading short files, you can use less to read longer files and move about your files using keyboard commands.
